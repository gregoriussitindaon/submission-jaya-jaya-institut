# Prototype Prediksi Risiko Dropout Mahasiswa — Jaya Jaya Institut

Prototype Streamlit untuk memprediksi risiko dropout mahasiswa, dibangun sebagai bagian dari
Proyek Akhir Dicoding "Menyelesaikan Permasalahan Institusi Pendidikan".

Repository lengkap (notebook, EDA, dashboard, dokumentasi) ada pada submission Dicoding
`submission_gregorius_bugen_ud8a`. Repository ini hanya berisi file minimal yang dibutuhkan
untuk deployment Streamlit Community Cloud.

Jalankan secara lokal:
```
pip install -r requirements.txt
streamlit run app.py
```
